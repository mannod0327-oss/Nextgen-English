38

If I do ... and If I did ...

If I do ... va If I did ... (1- va 2-shart)
If and wish · Shart gaplar va wish

🎯 Bu darsda nimani o‘rganasiz?

  • If I do ... (if + present) — haqiqiy imkoniyat haqida: If I find it, I’ll tell you.
  • If I did ... (if + past) — xayoliy, tasavvurdagi vaziyat haqida: If I met a famous footballer, I’d ask for an autograph.
  • Nega if qismida would ishlatilmasligini (va bitta istisnoni).
  • Gapning ikkinchi qismida would / could / might ning farqini.
  • Bunday gaplarda nega when emas, if ishlatilishini.

Ingliz tilida shart gapning ikki asosiy turi bor. Agar biror narsa haqiqatan ham bo‘lishi mumkin deb o‘ylasak — if + present ..., will .... Agar biz shunchaki tasavvur qilayotgan bo‘lsak va bu bo‘lishini kutmasak — if + past ..., would .... Diqqat: ikkinchi turda fe’l o‘tgan zamon shaklida, lekin ma’no o‘tmish emas, balki hozir yoki kelajak!

O‘zbek tilida ham shunga o‘xshash farq bor: Topsam, olib kelaman (real) va Uchratib qolsam, dastxat so‘rardim (xayol). Ikkinchisida -ardim / -ar edim shakli ingliz tilidagi would ga to‘g‘ri keladi. Asosiy farq: o‘zbekchada shart qismi ko‘pincha bir xil (-sa), inglizchada esa if dan keyingi fe’l o‘zgaradi: find → found, have → had, is → was / were.

Haqiqiy imkoniyat va xayoliy vaziyat If I find ..., I’ll ... and If I found ..., I’d ...

1-vaziyat. Jasur ko‘k sharfini topa olmayapti. U sharfni hamkasbi Azizning mashinasida qoldirgan bo‘lishi mumkin:

  • JASUR: Have you seen my blue scarf? Maybe I left it in your car.
    AZIZ: I haven’t noticed it, but I’ll check this evening. If I find it, I’ll bring it to work tomorrow.    JASUR: Ko‘k sharfimni ko‘rmadingmi? Balki mashinangda qoldirgandirman. AZIZ: E’tibor bermagan ekanman, lekin kechqurun qarab ko‘raman. Topsam, ertaga ishga olib kelaman.

Aziz sharfni topishi haqiqatan ham mumkin deb o‘ylaydi. Shuning uchun u If I find ..., I’ll ... deydi.

2-vaziyat. Bekzod do‘stlari bilan gaplashib o‘tiribdi va shunday deydi:

  • BEKZOD: If I met a famous footballer, I’d ask him for an autograph.BEKZOD: Agar mashhur futbolchini uchratib qolsam, undan dastxat so‘rardim.

Bu boshqacha vaziyat. Bekzod mashhur futbolchini uchratishini kutmayapti, u shunchaki tasavvur qilyapti: “agar shunday bo‘lsa-chi?” Shuning uchun u If I met ..., I’d (= I would) ... deydi — If I meet ..., I’ll ... emas.

Ikki tuzilma yonma-yon
if qismiasosiy qismMisol
Haqiqiy imkoniyatif + present simplewill + fe’lIf I see Aziz tomorrow, I’ll give him the book.
Xayoliy vaziyatif + past simplewould + fe’lIf I had a garden, I’d grow tomatoes.

Qoida: Biror vaziyatni tasavvur qilganda if + past ishlatamiz (if I found / if there was / if we didn’t ...). Fe’l o‘tgan zamonda bo‘lsa ham, ma’no o‘tmish emas — gap hozir yoki kelajak haqida.

  • If you could live in any city in the world, where would you live?Dunyoning istalgan shahrida yashay olsangiz, qayerda yashardingiz? (shunchaki tasavvur)
  • I’d love to stay in bed today, but I’m going to work. My boss would be angry if I stayed at home.Bugun to‘shakdan turgim yo‘q, lekin ishga boraman. Uyda qolsam, boshlig‘imning jahli chiqardi.
  • If there was an earthquake now, what would you do?Hozir zilzila bo‘lsa, nima qilardingiz?
  • If I won a free trip anywhere in the world, I’d go to Japan.Dunyoning istalgan joyiga bepul sayohat yutib olsam, Yaponiyaga borardim.

If there was ... o‘rniga If there were ... ham deyish mumkin. was / were farqi Unit 39 (C bo‘lim) da batafsil tushuntiriladi.

Bitta voqea — ikki xil gap: hammasi sizning fikringizga bog‘liq

Ba’zan bir xil voqea haqida ikkala tuzilmani ham ishlatish mumkin. Qaysi birini tanlash — siz bu voqea bo‘lishiga qanchalik ishonishingizga bog‘liq:

Real (bo‘lishi mumkin)Xayoliy (kutilmaydi)
If it rains tomorrow, we’ll stay at home.
Ertaga yomg‘ir yog‘sa, uyda qolamiz.		If it snowed in Tashkent in July, everybody would be amazed.
Toshkentda iyulda qor yog‘sa, hamma hayratda qolardi.
If you ask Nodira, she’ll help you. She’s very kind.
Nodiradan so‘rasangiz, u yordam beradi. U juda mehribon.		If you asked the president for help, would he answer?
Prezidentdan yordam so‘rasangiz, u javob berarmidi?

if qismida would ishlatilmaydi Not “if ... would”

Odatda gapning if bilan boshlanadigan qismida would qo‘yilmaydi. would faqat ikkinchi (asosiy) qismda keladi:

  • I’d be terrified if a stranger followed me home at night. (not if a stranger would follow)Tunda notanish odam meni uyimgacha kuzatib kelsa, juda qo‘rqib ketardim.
  • If I didn’t water the plants, they’d die. (not If I wouldn’t water)Gullarni sug‘ormasam, ular qurib qolardi.
  • If the buses came on time, I wouldn’t be late so often. (not If the buses would come)Avtobuslar o‘z vaqtida kelganida edi, men bunchalik tez-tez kechikmasdim.
If+ega+past simple,ega+would (’d)+fe’l

Istisno: kimdandir nimadir so‘raganda

Kimdandir iltimos qilganda (ayniqsa rasmiy xat va e-mailda) if ... would ishlatish mumkin. Bu yerda would “rozi bo‘lsangiz, iltimos” ma’nosini beradi:

  • (in a formal email) I would be grateful if you would send me the documents by Friday.(rasmiy xatda) Hujjatlarni juma kunigacha yuborsangiz, minnatdor bo‘lardim.
  • It would be very kind of you if you would help me with my application.Arizamni tayyorlashda yordam bersangiz, katta yaxshilik qilgan bo‘lardingiz.

Bunday iltimoslarda if you could ham juda ko‘p ishlatiladi: I’d be grateful if you could send me the documents. Ikkalasi ham to‘g‘ri va xushmuomala.

Ikkinchi qism: would, could, might would (’d) / wouldn’t; could and might

Gapning if bo‘lmagan qismida would (’d) / wouldn’t ishlatamiz:

  • If you went to bed earlier, you’d feel less tired.Ertaroq yotsangiz, kamroq charchardingiz.
  • I’ve got a sore throat. If I sang tonight, I wouldn’t sound very good.Tomog‘im og‘riyapti. Bugun kechqurun qo‘shiq aytsam, ovozim unchalik yaxshi chiqmasdi.
  • Would you mind if I opened the window? It’s very hot in here.Derazani ochsam, qarshi emasmisiz? Bu yer juda issiq.

would o‘rniga could va might ham kelishi mumkin — ular ma’noni o‘zgartiradi:

would / could / might — asosiy qismda
So‘zMa’nosiMisol
wouldnatija aniq: “... bo‘lardi / qilardim”If I had more free time, I would visit my grandparents more often.
Bo‘sh vaqtim ko‘proq bo‘lsa, buvim va bobomnikiga tez-tez borardim.
could= would be able to: “... qila olardik”If I had more free time, I could visit my grandparents more often.
Bo‘sh vaqtim ko‘proq bo‘lsa, buvim va bobomnikiga tez-tez bora olardim.
might= perhaps would: “balki ... bo‘lardi”If you asked Malika, she might help you.
Malikadan so‘rasangiz, balki u sizga yordam berardi.
  • If we left now, we might catch the last train. (= perhaps we would catch it)Hozir chiqsak, balki oxirgi poyezdga ulgurardik.
  • If I had a car, I could drive you to the airport. (= I would be able to drive you)Mashinam bo‘lganida, sizni aeroportga olib bora olardim.

Qisqa shakl ’d = would (bu unitda). I’d go, she’d help, we’d feel. Inkor: wouldn’t = would not. So‘roq: Would you ...? Qisqa javob: Yes, I would. / No, I wouldn’t.

Bunday gaplarda when emas, if if, not when

when — biz aniq bo‘ladi deb bilgan narsa uchun. Tasavvur qilinayotgan vaziyatlarda esa faqat if ishlatiladi:

  • My parents would worry if I didn’t phone them every evening. (not when I didn’t phone)Har kuni kechqurun qo‘ng‘iroq qilmasam, ota-onam xavotir olardi.
  • What would you do if you lost your passport abroad? (not when you lost)Chet elda pasportingizni yo‘qotib qo‘ysangiz, nima qilardingiz?

when — aniq bo‘ladi

I’ll call you when I get home.

Uyga albatta boraman — faqat qachonligi masala.

if — balki bo‘ladi / xayol

I’d call the police if somebody broke into my house.

Bu bo‘lishini kutmayman, faqat tasavvur qilyapman.

when va if farqi haqida ko‘proq — Unit 25.

Gap tuzilishi, vergul va qisqa shakllar Word order, commas and short forms

Ko‘p o‘qituvchilar va darsliklar bu ikki tuzilmani first conditional (if + present, will) va second conditional (if + past, would) deb ataydi. Murphy kitobida bu atamalar ishlatilmaydi, lekin ular aynan shu ikki tuzilmani bildiradi.

⚠️ Ko‘p uchraydigan xatolar Common mistakes

If I would have money, I would buy a car.If I had money, I would buy a car.if qismida would ishlatilmaydi — o‘rniga past simple.
If I will see him, I’ll tell him.If I see him, I’ll tell him.Real shartda ham if qismida will emas, present simple.
If I met a famous footballer, I will ask him for an autograph.If I met a famous footballer, I would (I’d) ask him for an autograph.if + past bilan asosiy qismda will emas, would keladi. Tuzilmalarni aralashtirmang.
What would you do when you lost your keys?What would you do if you lost your keys?Xayoliy vaziyatda when emas, if.
If you asked him, he would to help you.If you asked him, he would help you.would dan keyin “to” qo‘yilmaydi.
If I won the lottery, I would bought a house.If I won the lottery, I would buy a house.O‘tgan zamon faqat if qismida. would dan keyin fe’lning oddiy shakli.
I would happy if you came.I would be happy if you came.Sifatdan oldin be kerak: would be happy / would be angry.
If she wouldn’t be so tired, she would come.If she wasn’t (weren’t) so tired, she would come.if qismida “wouldn’t be” emas, was / were not.

❓ Savol-javob Questions students often ask

Nega fe’l o‘tgan zamonda, lekin ma’no hozir yoki kelajak?

Ingliz tilida o‘tgan zamon shakli faqat vaqtni emas, “haqiqatdan uzoqlik”ni ham bildiradi. If I met a famous footballer — “bu haqiqatdan uzoq, faqat tasavvur”. Shuning uchun shakl o‘tgan zamon, ma’no esa hozir/kelajak. Xuddi shu hodisani I wish I knew (Unit 39) va It’s time we went (Unit 35) da ham ko‘rasiz.

“If I get the job, I’ll ...” va “If I got the job, I’d ...” — qaysi biri to‘g‘ri?

Ikkalasi ham to‘g‘ri. Farq — sizning ishonchingizda. Ishga olinishingiz real deb o‘ylasangiz — If I get. Bunga unchalik ishonmasangiz yoki shunchaki orzu qilayotgan bo‘lsangiz — If I got.

’d — bu would mi yoki had mi?

Ikkalasi ham bo‘lishi mumkin. Keyingi so‘zga qarang: ’d + fe’lning oddiy shakli (go, buy, be) = would: I’d go. ’d + V3 (gone, seen, known) = had: I’d seen it (Unit 40). ’d better esa had better (Unit 35).

if qismini gapning oxiriga qo‘ysam bo‘ladimi?

Ha, bemalol: I’d be happy if you came. = If you came, I’d be happy. Ma’no bir xil. if-qism boshida bo‘lsa, odatda undan keyin vergul qo‘yiladi.

if qismida “would” ni umuman ishlatib bo‘lmaydimi?

Odatda yo‘q. Faqat xushmuomala iltimosda mumkin: I’d be grateful if you would reply soon. Bu yerda would “rozi bo‘lsangiz” degan ma’noda. Boshqa hollarda if dan keyin past simple ishlating.

could va might ning farqi nima?

could = qila olardi (imkoniyat, qobiliyat): If I had a car, I could drive you. might = balki ... bo‘lardi (ishonch yo‘q): If you asked her, she might agree. would esa natija aniq ekanini bildiradi.

if + present bilan faqat will ishlatiladimi?

Yo‘q. Real shartdan keyin can, may, might, should yoki buyruq ham kelishi mumkin: If you see Sardor, tell him to call me. If it rains, we might stay at home. Asosiysi — if qismida present simple.

✍️ Mashqlar Practice

1-mashq. To‘g‘ri variantni tanlang.

  1. If I (will see / see) Sardor tomorrow, I’ll tell him the news.
  2. If I (had / would have) more money, I’d buy a new phone.
  3. What (will / would) you do if you found a snake in your bed?
  4. If it (rains / rained) tomorrow, we’ll stay at home.
  5. I’d be very surprised if Jasur (forgot / would forget) my birthday.
  6. If you took a taxi, you (’ll / ’d) get there faster.
  7. What would you do (when / if) you saw a ghost?
  8. If we left now, we (might / will) catch the last bus.

2-mashq. Xayoliy vaziyat: qavs ichidagi fe’llarni if + past simple va would + fe’l shaklida yozing.

  1. If I (live) near the sea, I (swim) every day.
  2. What you (do) if somebody (steal) your bag?
  3. If Aziz (not / be) so busy, he (come) with us.
  4. If you (move) to Samarkand, you (miss) your friends?
  5. If the bazaar (close), many sellers (lose) their jobs.
  6. If I (win) a free trip, I (go) to Japan.

3-mashq. Xatoni toping va to‘g‘ri gapni yozing.

  1. If I would have time, I would help you. →
  2. If I will see her, I’ll give her your message. →
  3. If Jasur lived closer, I will visit him more often. →
  4. What would you do when you lost your keys? →
  5. If you asked him, he would to help you. →
  6. If she wouldn’t be so tired, she would come. →

4-mashq. Qavs ichidagi so‘zlardan foydalanib, xayoliy vaziyat haqida gap tuzing.

  1. (if / a famous singer / visit / our school / everybody / be / excited) →
  2. (if / I / lose / my phone / I / buy / a new one) →
  3. (you / feel / better / if / you / drink / more water) →
  4. (if / Nodira / speak / French / she / could / work / in Paris) →

5-mashq. Ingliz tiliga tarjima qiling.

  1. Agar ertaga Sardorni ko‘rsam, unga aytaman. →
  2. Hozir zilzila bo‘lsa, nima qilardingiz? →

🧠 Esda tuting

  • Real imkoniyat: if + present simple, will + fe’l — If I find it, I’ll tell you.
  • Xayoliy vaziyat: if + past simple, would + fe’l — If I found it, I’d tell you.
  • if + past da shakl o‘tgan zamon, lekin ma’no hozir / kelajak.
  • if qismida would ham, will ham ishlatilmaydi (istisno: xushmuomala iltimos — if you would ...).
  • Asosiy qismda: would (aniq natija), could (qila olardi), might (balki).
  • Xayoliy vaziyatlarda when emas, if.
