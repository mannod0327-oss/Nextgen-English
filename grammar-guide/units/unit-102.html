So and such

So va such
Adjectives and adverbs · Sifatlar va ravishlar

🎯 Bu darsda nimani o‘rganasiz?

  • so + sifat / ravish (so kind, so quickly) va such + (a/an) + (sifat) + ot (such a kind man, such nice people) farqini.
  • so / such ... that qolipi bilan natijani ifodalashni: It was so cold that we stayed at home.
  • Natijasiz, faqat ta’kid uchun ishlatiladigan so / such: I’m so tired! It’s such a lovely day!
  • so much / so many / so few / so little va such a lot (of) ni.
  • so long – such a long time, so far – such a long way juftliklarini.

so va such — ikkalasi ham “shunchalik, shunday” ma’nosini beradi va gapni kuchaytiradi. Ularni keyingi so‘z ajratadi: agar keyin sifat yoki ravish yolg‘iz kelsa — so; agar ot kelsa (oldidan sifat bo‘lsa ham, bo‘lmasa ham) — such.

O‘zbek tilida “shunday” (yoki shunchalik, shu qadar) so‘zi har ikkala holatda ham ishlatiladi: shunday yaxshi (so good) va shunday yaxshi odam (such a good person). Shuning uchun o‘zbek o‘quvchilari ko‘pincha so a good person yoki such good deb adashadi. Natija gapi esa o‘zbekchada -ki bilan keladi: shunchalik charchadimki, uxlab qoldim = I was so tired that I fell asleep. Inglizchadagi that aynan shu “-ki” ning o‘rnida turadi.

So va such: qaysi biri qachon? So + adjective/adverb; such + (a/an) + (adjective) + noun

Tanlov oddiy: so‘zdan keyin nima keladi? Rasmdagi sxemaga qarang.

Qoida: a / an faqat birlikdagi sanaladigan ot bilan keladi: such a nice day, lekin such nice days (ko‘plik) va such nice weather (sanalmaydigan ot). Tartib har doim: such + a / an + sifat + ot (a such nice day ❌).

  • The film was so boring that I left halfway.Film shunchalik zerikarli ediki, yarmida chiqib ketdim.
  • It was such a boring film.Bu juda zerikarli film edi.
  • Nodira is so clever. She is such a clever girl.Nodira shunchalik aqlli. U shunday aqlli qiz.
  • Jasur drives so carefully.Jasur shunchalik ehtiyotkorlik bilan haydaydi.
  • Thank you for such useful information.Bunday foydali ma’lumot uchun rahmat.

such a dan keyin sifat bo‘lmasa ham bo‘ladi — ot o‘zi kuchli ma’noli bo‘lganda: It’s such a pity! / That was such a mess! (mess = tartibsizlik). (Hayqiriqda esa What a pity! deymiz, What such a pity! ❌.) Ammo sifat yolg‘iz bo‘lsa, such ishlatilmaydi: She is such kind ❌ → She is so kind ✅.

Xato qolipga ehtiyot bo‘ling: He is so a good man ❌, She is such tired ❌, It was a such nice day ❌. To‘g‘ri: He is such a good man / so good, She is so tired, It was such a nice day.

So / such ... that — natija So/such ... that: result

Biror narsa shu darajada kuchliki, bu natijaga olib keldi, degan fikrni so / such ... that bilan aytamiz. that dan keyin to‘liq gap (ega + fe’l) keladi.

so + sifat/ravish + that

  • The bag was so heavy that I couldn’t lift it.
  • Jasur spoke so quietly that nobody heard him.
  • It was so hot that we stayed indoors.

such (a) + (sifat) + ot + that

  • It was such a heavy bag that I couldn’t lift it.
  • They had such a lot of homework that they stayed up late.
  • It was such terrible weather that the flight was cancelled.
  • I was so tired that I fell asleep on the bus.Shunchalik charchagan edimki, avtobusda uxlab qoldim.
  • It was such a funny film that we watched it again the next day.Film shunday kulgili ediki, ertasi kuni uni yana tomosha qildik.
  • Kamola was so nervous that she couldn’t eat anything.Kamola shunchalik hayajonlangan ediki, hech narsa yeya olmadi.
  • Dilnoza has such a lovely voice that everybody stops to listen.Dilnozaning ovozi shunday yoqimliki, hamma to‘xtab tinglaydi.
  • The stadium was so crowded that we couldn’t find our seats.Stadion shunchalik gavjum ediki, joylarimizni topa olmadik.

Og‘zaki nutqda that ko‘pincha tushirib qoldiriladi: I was so tired I fell asleep. Yozma va rasmiy matnda that ni saqlash yaxshi. that dan oldin vergul qo‘yilmaydi.

So ... that, too ... to va enough ... to

so ... that ko‘pincha too ... to (Unit 103) bilan bir xil fikrni beradi:

Bir fikr — ikki yo‘l
so ... thattoo ... to
The tea was so hot that I couldn’t drink it.The tea was too hot to drink.
She is so young that she can’t vote.She is too young to vote.

that bilan than ni adashtirmang: so tired than I fell asleep ❌ → so tired that I fell asleep ✅. Shuningdek so that (maqsad, Unit 64) boshqa narsa: I spoke slowly so that everybody could understand. (“hamma tushunishi uchun”). Natija qolipida so sifat/ravishdan oldin turadi: I spoke so slowly that everybody understood.

Faqat ta’kid uchun: so va such natijasiz So and such for emphasis, without “that”

Har doim ham natija gapi shart emas. so / such his-tuyg‘uni, hayratni, quvonchni yoki norozilikni kuchaytirish uchun ham ishlatiladi. Bunda that bo‘lmaydi. Og‘zaki nutqda so va such ga urg‘u beriladi.

  • I’m so glad you could come!Kelganingizdan juda xursandman!
  • Thank you so much.Katta rahmat.
  • I’m so sorry I’m late.Kechikkanim uchun juda uzr.
  • You’re such a good cook!Siz shunday yaxshi oshpazsiz!
  • It’s such a long time since we last met.Oxirgi marta uchrashganimizga shunday ko‘p vaqt bo‘ldi.
  • Don’t be so silly!Bunchalik bema’nilik qilmang!

So va such = “bunchalik, bunaqa” (like this)

so / such ba’zan “shu darajada, bunaqa” ma’nosini beradi: biror narsa biz kutganimizdan (yoki odatdagidan) shunchalik farq qiladi:

  • I knew the bazaar was big, but I didn’t expect it to be so big.Bozorning kattaligini bilardim, lekin bunchalik katta deb kutmagandim.
  • I don’t usually go to bed so late.Odatda bunchalik kech yotmayman.
  • I’ve never eaten such delicious plov.Hech qachon bunaqa mazali palov yemaganman.
  • “Fastly”? There’s no such word in English.“Fastly”mi? Ingliz tilida bunday so‘z yo‘q.

no such + ot = “bunday ... yo‘q, mavjud emas”: There’s no such person in our class. (Sinfimizda bunday odam yo‘q.)

O‘zbekchada “qanday ajoyib kun!” deymiz. Inglizchada bu ma’no ikki yo‘l bilan beriladi: It’s such a lovely day! yoki What a lovely day! Sifat yolg‘iz bo‘lsa — How lovely! (so lovely ham bo‘ladi). What va how haqida FAQ bo‘limiga qarang.

So much, so many, so few, so little va such a lot (of) So much/many/few/little; such a lot (of)

much, many, few, little (Unit 87) oldidan so keladi, such emas. Ularni sanaladigan/sanalmaydigan otga qarab tanlaymiz:

such many people ❌, such much traffic ❌, such few students ❌. To‘g‘ri: so many people, so much traffic, so few students. Yana: I’m so much tired ❌ → I’m so tired ✅ (sifat oldidan so much emas).

Natija ham qo‘shilishi mumkin: There was so much snow that the roads were closed. (Yo‘llar yopilib qoldi.) She has so many friends that she is never lonely.

Such a lot (of)

Britaniya ingliz tilida norasmiy nutqda such a lot (of) ham ishlatiladi. U so much / so many bilan bir xil ma’noni beradi va ham sanaladigan, ham sanalmaydigan otlar bilan keladi:

  • There was such a lot of traffic. (= so much traffic)Tirbandlik shunday katta edi.
  • There were such a lot of people. (= so many people)Odam shunday ko‘p edi.
  • I’ve got such a lot to do today.Bugun qiladigan ishlarim shunday ko‘p.

so much yana qiyoslash darajasi (comparative) oldida ham keladi: I feel so much better today. (Bugun ancha yaxshi his qilyapman.) Va ravish sifatida fe’ldan keyin: I love Bukhara so much. such a lot esa Amerika inglizchasida kam uchraydi; u yerda so much / so many yoki a lot aytiladi.

So long – such a long time; so far – such a long way Time and distance

Vaqt va masofa haqida gapirganda ham so yoki such ni tanlash qoidasi o‘sha-o‘sha: ot (time, way) bor bo‘lsa — such a ...; ot yo‘q bo‘lsa — so.

Vaqt va masofa

for so long time ❌, for such long time ❌, such a long (otsiz) ❌, so a long way ❌. To‘g‘ri: for so long yoki for such a long time; so far yoki such a long way.

so far yana bir ma’noda ham ishlatiladi: “hozirgacha”. Bu ham present perfect bilan keladi:

  • So far I’ve answered ten questions.Hozirgacha o‘nta savolga javob berdim.
  • So far, so good.Hozircha hammasi joyida.

❓ Savol-javob Questions students often ask

Nega “such a nice day”, lekin “such nice days” va “such nice weather”?

a / an faqat birlikdagi sanaladigan ot oldida turadi. day — birlik (a day), days — ko‘plik (a yo‘q), weather — sanalmaydigan ot (a yo‘q). Shuning uchun such a nice day, such nice days, such nice weather.

“So” bilan “very” ning farqi nimada?

very — neytral “juda”. so — his-tuyg‘uli “shunchalik” va ko‘pincha natijaga ishora qiladi. It’s very cold. oddiy fikr; It’s so cold! — hissiyot; It’s so cold that I can’t go out. — natija. Natija gapi bilan very ishlatilmaydi: very cold that ❌.

“So kind a man” degan gap to‘g‘rimi?

Grammatik jihatdan to‘g‘ri (so + sifat + a + ot), lekin juda kitobiy va eskicha, kundalik nutqda deyarli ishlatilmaydi: so kind a man o‘rniga such a kind man deng.

“What a lovely day!” bilan “It’s such a lovely day!” bir xilmi?

Ma’nosi deyarli bir xil. What + (a/an) + (sifat) + ot! — hayqiriq gap: What a lovely day! What nice people! Sifat yolg‘iz bo‘lsa — How + sifat!: How lovely! Bu qoliplarda “such / so” ishlatilmaydi: What such a lovely day ❌.

“So that” bilan “so ... that” ning farqi nima?

so that — maqsad (“-sin uchun”): I left early so that I wouldn’t miss the bus. so ... that — natija (“shunchalik ... ki”): I was so tired that I fell asleep. Natija qolipida so va that o‘rtasida sifat/ravish bor.

“Such a lot of” ni qachon ishlataman?

Norasmiy Britaniya nutqida: There were such a lot of people. Yozma va rasmiy matnda so many / so much yoki a great many / a great deal of yaxshiroq. Amerika inglizchasida such a lot kam uchraydi.

“Such” ni sifat bilan yolg‘iz ishlatsam bo‘ladimi?

Yo‘q. She is such nice ❌. Sifat yolg‘iz bo‘lsa — so (so nice). Agar sifatdan keyin ot kelsa — such (such a nice girl). Ot bo‘lmasa, such bilan gap tugallanmaydi.

“So much” bilan “so” orasidagi farq nima?

so sifat/ravish bilan: so tired. so much fe’l bilan yoki sanalmaydigan ot bilan: I love it so much; so much time. Qiyosiy daraja oldida ham so much: so much better. Lekin sifat oldida emas: so much tired ❌.

✍️ Mashqlar Practice

1-mashq. Bo‘sh joyga so yoki such yozing.

  1. It was a nice evening.
  2. The soup is salty.
  3. They are kind people.
  4. Why are you walking slowly?
  5. We had good weather in Fergana.
  6. I’m pleased to see you!
  7. Malika is a clever girl.
  8. He talks quickly that I can’t understand him.

2-mashq. Bo‘sh joyga so much, so many, so few, so little yoki so / such ni yozing.

  1. I can’t come. I have homework. (juda ko‘p, sanalmaydigan)
  2. There were people at the bazaar that we couldn’t move.
  3. Hurry up! We have time. (juda oz)
  4. There were students in the class that the lesson was cancelled. (juda kam, ko‘plik)
  5. It’s a long way to the village.
  6. I haven’t seen you for long!
  7. She has friends that she is never lonely. (juda ko‘p)
  8. Thank you much for your help.

3-mashq. Ikki gapni so ... that yoki such ... that bilan bitta gapga birlashtiring.

  1. The bag was very heavy. I couldn’t lift it. (so ... that) →
  2. It was a very interesting museum. We went back the next day. (such ... that) →
  3. She speaks very quickly. Nobody can follow her. (so ... that) →
  4. It was very bad weather. We stayed at home. (such ... that) →
  5. There were a lot of people at the concert. We couldn’t find a seat. (so many ... that) →
  6. He has very little free time. He never goes out. (so little ... that) →

🧠 Esda tuting

  • so + sifat / ravish: so kind, so quickly. such + (a/an) + (sifat) + ot: such a kind man, such nice people.
  • a / an faqat birlikdagi sanaladigan ot bilan: such a day, such days, such weather. Tartib: such a nice day (a such ❌).
  • Natija: so / such ... that + gap. Og‘zaki nutqda that tushirilishi mumkin. than emas, that.
  • Natijasiz ta’kid ham bo‘ladi: I’m so tired! It’s such a pity! “Bunchalik / bunaqa” ma’nosida: I didn’t expect it to be so big. There’s no such word.
  • so much / so many / so few / so little — so bilan, such many ❌. such a lot (of) — norasmiy BrE.
  • Ot yo‘q — so long, so far; ot bor — such a long time, such a long way.
  • so that (maqsad), so (shuning uchun) va such as (masalan) — boshqa iboralar.
