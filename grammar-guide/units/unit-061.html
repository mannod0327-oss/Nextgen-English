61

Be/get used to something (I'm used to ...)

Be / get used to — ko‘nikkan bo‘lmoq
-ing and to ... · -ing shakli va to + fe’l

🎯 Bu darsda nimani o‘rganasiz?

  • I’m used to something — “bu menga g‘alati emas, ko‘nikkanman” degan holatni.
  • I’m getting used to / I got used to — “ko‘nika boshladim / ko‘nikib qoldim” degan jarayonni.
  • used to do (Unit 18, o‘tmishdagi odat) va be used to doing (ko‘nikkan bo‘lmoq) orasidagi katta farqni.
  • used to dan keyin ot yoki -ing kelishini (infinitiv emas!).

Uchta ibora bir-biriga juda o‘xshaydi, lekin ma’nolari butunlay boshqa:

Bir qarashda: used to / be used to / get used to
IboraMa’nosiMisol
used to + fe’lavval shunday bo‘lgan, endi yo‘qI used to live in Fergana.
be used to + ot / -ingko‘nikkan (g‘alati emas)I’m used to living in Tashkent.
get used to + ot / -ingko‘nikmoq, ko‘nikib bormoqI’m getting used to living here.

O‘zbek tilida uchta ma’no uchta turli shakl bilan beriladi: yashardim / yashar edim (used to do), yashashga ko‘nikkanman (be used to doing) va yashashga ko‘nika boshladim / ko‘nikib qoldim (get used to doing). Inglizchada esa uchalasida ham used to bor, farq faqat oldidagi so‘zda (be / get / hech narsa) va keyingi fe’l shaklida (-ing / oddiy fe’l). Shu sababli o‘quvchilar ularni tez-tez chalkashtiradi.

I’m used to something: ko‘nikkan holat I’m used to something = it’s not strange or difficult for me

Biror narsani ko‘p marta qilgan yoki uzoq vaqt boshingizdan o‘tkazgan bo‘lsangiz, u sizga endi g‘alati yoki qiyin emas. Mana shu holat be used to bilan aytiladi:

Ega+am / is / are / was / were+used to+ot / olmosh / fe’l-ing
  • Malika has lived near the bazaar for years. She’s used to the noise.Malika bozor yonida yillar davomida yashagan. U shovqinga ko‘nikkan.
  • “Aren’t you cold?” “No, I’m used to cold weather. I grew up in the mountains.”— Sovqotmayapsizmi? — Yo‘q, sovuq havoga ko‘nikkanman. Tog‘da o‘sganman.
  • Jasur is used to getting up at five. He’s a baker.Jasur soat beshda turishga ko‘nikkan. U novvoy.
  • I’m not used to speaking in front of a lot of people.Men ko‘p odam oldida gapirishga ko‘nikmaganman.
  • Are you used to the food here?Bu yerdagi ovqatga ko‘nikkanmisiz?
  • When I first moved to Tashkent, I wasn’t used to the traffic.Toshkentga yangi ko‘chib kelganimda tirbandlikka ko‘nikmagan edim.
  • Dilnoza is used to her husband working late. She doesn’t mind.Dilnoza erining kech ishlashiga ko‘nikkan. U bunga qarshi emas. (used to + kimdir + -ing)
be used to: har xil shakllar
ShaklMisolO‘zbekcha
Darak (hozir)She is used to working at night.U kechasi ishlashga ko‘nikkan.
Inkor (hozir)She isn’t used to the cold.U sovuqqa ko‘nikmagan.
So‘roqAre you used to working from home?Uydan turib ishlashga ko‘nikkanmisiz?

Kelasi zamonDon’t worry, in a month you’ll be used to it.Xavotir olmang, bir oydan keyin ko‘nikib qolasiz.

Qoida: be used to dan keyin ot, olmosh (it, this) yoki fe’l + -ing keladi. Bu yerda to — predlog (Unit 60): I’m used to it ✅. Shuning uchun infinitiv emas: ❌ I’m used to get up early → ✅ I’m used to getting up early.

used so‘zida oxirgi -d harfini unutmang va be fe’lini tushirmang: ❌ I’m use to the noise, ❌ I used to the noise → ✅ I’m used to the noise. used bu yerda /juːst/ deb o‘qiladi (oxirida -st).

get used to: ko‘nikib bormoq Get used to something = become used to it

Avval narsa g‘alati va qiyin tuyuladi, vaqt o‘tib u odatiy bo‘lib qoladi. Mana shu o‘zgarish jarayoni get used to bilan aytiladi. Tuzilish be used to bilan bir xil: keyin ot yoki -ing.

  • It was strange at first, but I’m getting used to the new school.Avvaliga g‘alati edi, lekin yangi maktabga ko‘nikib bormoqdaman.
  • Don’t worry about the heat. You’ll soon get used to it.Issiqdan xavotir olmang. Tez orada ko‘nikib ketasiz.
  • After a few weeks, Dilnoza got used to getting up early.Bir necha haftadan keyin Dilnoza erta turishga ko‘nikib qoldi.
  • I can’t get used to the food here. I miss home cooking.Bu yerdagi ovqatga ko‘nika olmayapman. Uydagi taomlarni sog‘indim.
  • Have you got used to the traffic yet?Tirbandlikka hali ko‘nikdingizmi? (AmE: Have you gotten used to ...?)
  • Sardor has got used to cooking for himself.Sardor o‘ziga o‘zi ovqat pishirishga ko‘nikib qoldi.
be used to ↔ get used to: holat va jarayon
be used to (holat)get used to (jarayon)
Ma’noko‘nikkan, g‘alati emasko‘nikmoq, ko‘nikib bormoq
HozirI’m used to the heat.I’m getting used to the heat.
O‘tgan zamonI was used to the heat. (u paytda ko‘nikkan edim)I got used to the heat. (ko‘nikib qoldim)
Kelasi zamonI’ll be used to the heat soon.I’ll get used to the heat soon.
Present perfectI’ve been used to the noise for years.I’ve got used to the heat. (AmE: I’ve gotten used to)

Rasmiyroq uslubda become used to, become accustomed to ham ishlatiladi. get o‘rniga become qo‘ysangiz ma’no o‘zgarmaydi, lekin kundalik nutqda get used to ancha ko‘p uchraydi.

O‘zbekcha ko‘nikmoq inglizchaga ikki xil o‘giriladi: ko‘nikkanman → I’m used to (holat), ko‘nikib qoldim / ko‘nikyapman → I got used to / I’m getting used to (jarayon). Qaysi ma’no kerakligini o‘ylab tanlang.

I used to do va I’m used to doing: asosiy farq Used to (do) vs be used to (doing)

Bu ikki ibora talaffuzda deyarli bir xil, shuning uchun chalkashtirish oson. Ammo ma’no va tuzilish butunlay boshqa:

I used to + fe’l

O‘tmishdagi odat yoki holat, hozir yo‘q.

  • I used to live in a village. (endi yashamayman)
  • Nodira used to be afraid of dogs. (endi qo‘rqmaydi)

Faqat o‘tgan zamon. Keyin oddiy fe’l. Inkor/so‘roq: didn’t use to, did you use to?

I am used to + ot / -ing

Hozirgi (yoki istalgan paytdagi) ko‘nikkan holat.

  • I am used to living in a city. (men shunga ko‘nikkanman)
  • Nodira is used to being alone. (yolg‘izlikka ko‘nikkan)

Har qanday zamon (am, was, will be). Keyin ot yoki -ing.

MisolI used to drive to work.I’m used to driving to work.I’m getting used to driving to work.
O‘zbekchaIlgari ishga mashinada borardim.Ishga mashinada borishga ko‘nikkanman.Ishga mashinada borishga ko‘nikib bormoqdaman.

Qanday ajrataman? used to dan oldin va keyin nima turganiga qarang. Oldida am / is / are / was / get bor va keyin -ing yoki ot bo‘lsa — ko‘nikish. Oldida hech narsa yo‘q va keyin oddiy fe’l bo‘lsa — o‘tmishdagi odat. Yana sinov: used to o‘rniga accustomed to qo‘ya olsangiz, bu be used to.

  • I used to be afraid of dogs, but now I love them.Ilgari itlardan qo‘rqardim, hozir esa ularni yaxshi ko‘raman.
  • I’m used to being alone, so I don’t feel lonely.Yolg‘izlikka ko‘nikkanman, shuning uchun o‘zimni yolg‘iz his qilmayman.
  • We used to have a dog. Now we have a cat.Bizda ilgari it bor edi. Hozir mushugimiz bor.
  • We’re used to having guests on Fridays.Biz juma kunlari mehmon kutib olishga ko‘nikkanmiz.

Ilgari odatlar haqida batafsil — Unit 18 (used to do) va Unit 36 (would). would ba’zan used to ning o‘rnini bosadi, lekin be used to ning o‘rniga hech qachon ishlatilmaydi.

Qo‘shimcha: ikki “used” ni aralashtirmang Used to (accustomed) vs is used to + infinitive

used so‘zi yana bir ma’noda keladi — use (foydalanmoq) fe’lining majhul nisbati. Bunda used /juːzd/ deb o‘qiladi va keyin to + oddiy fe’l (maqsad) keladi:

Uch xil “used to”
TuzilmaMa’nosiMisol
I used to + fe’l /juːst/ilgari shunday ediI used to play chess.
I am used to + -ing /juːst/ko‘nikkanmanI am used to playing chess every day.
It is used to + fe’l /juːzd/shu maqsadda ishlatiladiThis tool is used to open bottles.
  • A thermometer is used to measure temperature.Termometr haroratni o‘lchash uchun ishlatiladi.

Oxirgisida “to” dan keyin oddiy fe’l bor va gap narsaning vazifasi haqida. Bu mavzu Unit 64 (maqsad) bilan ham bog‘liq.

❓ Savol-javob Questions students often ask

“used to” va “be used to” ni qanday ajrataman?

Ikki belgiga qarang. (1) used to dan oldin am / is / are / was / get bormi? Bo‘lsa — bu ko‘nikish. (2) used to dan keyin nima? Oddiy fe’l (used to live) — o‘tmishdagi odat; ot yoki -ing (used to the noise, used to living) — ko‘nikish. Ikkalasi bir-biriga mos kelishi shart: be used to + -ing.

Nega “I’m used to living” da -ing bor? “to” infinitiv emasmi?

Yo‘q, bu yerda to — predlog. Sinab ko‘ring: I’m used to it deyish mumkin. to dan keyin it qo‘ya olsangiz, u predlog va fe’l -ing bo‘ladi (Unit 60). Infinitiv belgisi bo‘lgan to dan keyin esa it qo‘yib bo‘lmaydi: I want to it ❌.

“I’m used to” va “I get used to” — farqi nima?

I’m used to the heat — natija: hozir ko‘nikkanman, qiyin emas. I’m getting used to the heat — jarayon: ko‘nika boshladim, hali to‘liq emas. I got used to the heat — jarayon tugadi, ko‘nikib qoldim. I’ll get used to it — kelajakda ko‘nikaman.

“I’m not used to ...” va “I didn’t use to ...” bir xilmi?

Yo‘q. I’m not used to getting up early — erta turish men uchun odatiy emas, qiyin. I didn’t use to get up early — ilgari erta turmasdim (o‘tmishdagi odat haqida, hozir o‘zgargan bo‘lishi mumkin).

“I was used to” va “I got used to” farqi nima?

I was used to the noise — o‘sha paytda shovqin menga odatiy edi (holat). I got used to the noise — avval odatiy emas edi, keyin odatiy bo‘lib qoldi (o‘zgarish). Masalan: When I lived near the airport, I was used to the noise. At first I couldn’t sleep, but I got used to it.

“have gotten used to” — to‘g‘rimi?

Amerika ingliz tilida ha: Have you gotten used to it? Britaniya ingliz tilida got ishlatiladi: Have you got used to it? Ikkalasi ham to‘g‘ri, faqat variantlar.

“would” bilan “be used to” ni almashtirsam bo‘ladimi?

Yo‘q. would faqat o‘tmishda takrorlanadigan harakatlar haqida (When I was a child, we would play outside) used to do ning o‘rnini bosishi mumkin. be used to (ko‘nikkan) ma’nosida would ishlatilmaydi.

“accustomed to” nima? U “used to” bilan bir xilmi?

Ha, ma’nosi bir xil, lekin accustomed to rasmiyroq: I’m accustomed to working late = I’m used to working late. Undan keyin ham -ing yoki ot keladi.

🧠 Esda tuting

  • used to + oddiy fe’l — ilgari shunday edi, hozir yo‘q (faqat o‘tgan zamon). Inkor: didn’t use to.
  • be used to + ot / -ing — ko‘nikkan, g‘alati emas (har qanday zamonda): I’m used to the noise / to living here.
  • get used to + ot / -ing — ko‘nikmoq, ko‘nikib bormoq: I’m getting used to it, I got used to it, I’ll get used to it.
  • Ko‘nikish iboralaridagi to — predlog, shuning uchun keyin -ing (infinitiv emas).
  • Ajratish: be / get bor va keyin -ing yoki ot bo‘lsa — ko‘nikish; yo‘q va keyin oddiy fe’l bo‘lsa — ilgari odat.
  • BrE: have got used to; AmE: have gotten used to. would faqat used to do o‘rnini bosadi, be used to ni emas.

Bog‘liq mavzular: Unit 18 (used to do), Unit 36 (would), Unit 60 (predlog + -ing; to — predlog), Unit 7 (present perfect: have got used to), Unit 64 (to ... va for ...: maqsad), Unit 62 (fe’l + predlog + -ing).
