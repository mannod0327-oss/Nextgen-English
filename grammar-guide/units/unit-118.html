Like / as if / as though

Like / as if / as though — go‘yo
Conjunctions and prepositions · Bog‘lovchilar va predloglar

🎯 Bu darsda nimani o‘rganasiz?

  • look / sound / feel / smell / taste + like + ot — “…ga o‘xshaydi”: She looks like a film star.
  • look / sound / feel + as if / as though + gap — “go‘yo …dek”, “…ga o‘xshaydi”: It looks as if it’s going to rain.
  • like ning gap bilan ishlatilishi (It looks like it’s going to rain) norasmiy ekanini.
  • as if + o‘tgan zamon — haqiqatga to‘g‘ri kelmaydigan, xayoliy holat: He talks as if he knew the city well (aslida bilmaydi).
  • act, behave, talk, spend, run kabi boshqa fe’llar bilan as if: Don’t talk to me as if I were a child.

Biror narsaning ko‘rinishi, ovozi, hidi, ta’mi yoki tuyg‘usi haqida gapirganda, ikkita qurilishdan birini tanlaymiz. Ot bo‘lsa — like; to‘liq gap (ega + fe’l) bo‘lsa — as if yoki as though.

O‘zbek tilida bu ikki qurilish ham bir xil ko‘rinishda: “kino yulduziga o‘xshaydi” (like + ot) va “yomg‘ir yog‘adiganga o‘xshaydi” (as if + gap). Ma’no xayoliy bo‘lsa, o‘zbekcha go‘yo ...dek deydi: “go‘yo shaharni yaxshi biladigandek gapiradi”. Muhim farq: o‘zbekchada fe’l zamonini o‘zgartirmaymiz (biladigandek), inglizchada esa shu xayoliy holat uchun o‘tgan zamon ishlatiladi: as if he knew the city well. O‘zbek o‘quvchilar ko‘pincha shu yerda hozirgi zamonni qoldirishadi.

look, sound, feel, smell, taste fe’llaridan keyin narsa nimaga o‘xshashini aytmoqchi bo‘lsak, like + ot (yoki olmosh) ishlatamiz. Har bir fe’l bitta sezgi organiga mos keladi:

Look + sifat va look like + ot

Fe’ldan keyin sifat kelsa, like kerak emas (Unit 99). like faqat ot yoki olmosh oldidan keladi:

You look tired.You look like a tired traveller.

Sezgi fe’llari + as if / as though + gap It looks as if it’s going to rain

Sezgi fe’lidan keyin to‘liq gap (ega + fe’l) kelsa, as if yoki as though ishlatiladi. Ikkalasining ma’nosi bir xil, as though biroz yozma uslubga yaqin. Bu qurilish ko‘rinish, ovoz va hid asosida xulosa chiqarish uchun ishlatiladi.

Ega+look / sound / feel / smell / seem+as if / as though+ega+fe’l

  • Listen! It sounds as if somebody is knocking at the door.Quloq soling! Kimdir eshikni taqillatayotganga o‘xshaydi.
  • Aziz looks as though he’s about to faint.Aziz hushidan ketgudek ko‘rinadi.
  • The kitchen smells as if somebody has burnt the rice.Oshxonadan kimdir guruchni kuydirganday hid kelyapti.
  • It looks as though the match has been cancelled.O‘yin bekor qilinganga o‘xshaydi.

Qoida: Agar gapirayotgan narsangiz haqiqat bo‘lishi mumkin (rost bo‘lishi ehtimoli bor) bo‘lsa, as if dan keyin odatdagi zamon (vaziyatga mos zamon) ishlatiladi: It looks as if it is going to rain (haqiqatan yomg‘ir yog‘ishi mumkin).

It looks as if ... / It sounds as if ...

Ega it bo‘lsa, gap umumiy vaziyat haqidagi xulosani bildiradi: “…ga o‘xshaydi”, “chamasi …”. Hikoya o‘tgan zamonda bo‘lsa, as if dan keyingi fe’l ham odatda o‘tgan zamonga o‘tadi:

  • Malika is very late. It looks as if she has missed the bus.Malika juda kechikyapti. Avtobusdan qolib ketganga o‘xshaydi.
  • We stayed inside because it looked as if it was going to snow.Qor yog‘adiganga o‘xshagani uchun uyda qoldik.

Like — norasmiy variant

Og‘zaki nutqda as if / as though o‘rniga ko‘pincha like aytiladi. Bu juda keng tarqalgan va Amerika inglizchasida ayniqsa odatiy:

Rasmiy yoki yozmaNorasmiy (og‘zaki)
It looks as if it’s going to snow.It looks like it’s going to snow.
You sound as though you have just woken up.You sound like you have just woken up.
It seems as if nobody is at home.It seems like nobody is at home.

Imtihon va rasmiy yozuvda as if / as though ishlating. like + gap ni suhbatda eshitsangiz, tushunib oling, lekin yozma ishda undan ehtiyot bo‘ling. like + ot esa har doim to‘g‘ri: It looks like rain.

As if boshqa fe’llar bilan act, behave, talk, spend, run, treat ...

as if / as though faqat sezgi fe’llari bilan emas, har qanday fe’ldan keyin kelib, harakat qanday usulda bajarilishini tasvirlaydi: “go‘yo … bo‘lgandek”. Norasmiy nutqda bu gaplarda ham like eshitiladi. (Quyidagi misollarning ko‘pida o‘tgan zamon bor, chunki holat xayoliy — sababi D bo‘limida.)

It is / was as if ...

It is as if ... / It was as if ... ham tez-tez uchraydi. Bunda ham xayoliy holat uchun o‘tgan zamon ishlatiladi:

  • When I came back to the village, it was as if I had never left.Qishloqqa qaytganimda go‘yo u yerdan hech qachon ketmagandek his qildim.
  • The streets are so empty — it’s as if everybody had left the city.Ko‘chalar shunchalik bo‘m-bo‘shki, go‘yo hamma shahardan ketib qolgandek.

As if + o‘tgan zamon: xayoliy holat as if + past = not real

Ba’zan as if dan keyin gapda aytilgan narsa aslida rost emas. Masalan, kimdir shaharni yaxshi biladigandek gapiradi, lekin aslida bilmaydi (birinchi marta kelgan). Shunda inglizchada o‘tgan zamon ishlatiladi, garchi gap hozirgi payt haqida bo‘lsa ham. O‘tgan zamon “bu haqiqat emas” degan ishorani beradi (xuddi If I knew ... va I wish I knew ... da bo‘lgani kabi, Unit 39 va Unit 41).

  • Jasur talks as if he were the director, but he is only a trainee.Jasur go‘yo direktordek gapiradi, aslida u shunchaki stajyor.
  • Sardor spends money as if he was a millionaire.Sardor go‘yo millionerdek pul sarflaydi.
  • Nodira behaves as though she owned the building.Nodira go‘yo bino o‘zinikidek o‘zini tutadi.
  • Bekzod acted as if nothing had happened.Bekzod go‘yo hech narsa bo‘lmagandek o‘zini tutdi.
  • She looked at me as though she had never seen me before.U menga go‘yo meni hech ko‘rmagandek qaradi.
Zamonni tanlash: ikki qiyosiy gap
Haqiqat bo‘lishi mumkinXayoliy (rost emas)
Dilnoza looks as if she has been crying. (ko‘zlari qizargan — bu rost bo‘lishi mumkin)Dilnoza talks as if she were a famous singer. (u mashhur xonanda emas)
It sounds as if they are arguing. (eshityapman, rost bo‘lishi mumkin)He shouts as if I were deaf. (men kar emasman)

Xayoliy holatda be fe’li uchun were ham, was ham ishlatiladi. as if he were the boss — an’anaviy, rasmiy shakl; as if he was the boss — og‘zaki nutqda keng tarqalgan. “I” bilan ham shunday: as if I were / was a child. Siz ham ikkalasini ishlatsangiz bo‘ladi.

O‘zbek tilidan tarjima qilganda o‘tgan zamonni unutmang: go‘yo shaharni yaxshi biladigandek gapiradi → ❌ talks as if he knows the city well (rost bo‘lishi mumkin deb tushuniladi) → ✅ talks as if he knew the city well (aslida bilmaydi).

Oxirgisi — butunlay boshqa ma’no: bu yerda feel like “istamoq, xohlamoq” degani. U ko‘pincha inkor va savolda uchraydi: I don’t feel like cooking tonight. (Bugun kechqurun ovqat pishirgim kelmayapti.)

⚠️ Ko‘p uchraydigan xatolar Common mistakes

You look like tired.You look tired. / You look as if you are tired.Fe’ldan keyin sifat kelsa, like kerak emas. Like faqat ot yoki olmosh oldidan keladi.
She looks as a film star.She looks like a film star.Ot bilan like ishlatiladi. “As + ot” rol degani (Unit 117).
How does your brother look like?What does your brother look like?Ko‘rinishni so‘raganda “How” emas, “What ... look like” deyiladi. Like ni tushirib, “How does he look?” deyish ham mumkin, lekin bu boshqa savol: odatda sog‘lig‘i yoki kayfiyati qanday ko‘rinishi haqida.
The soup tastes like salty.The soup tastes salty.Sifat oldidan like kerak emas. Ot bilan: tastes like salt.
He talks as if he knows the city well. (aslida bilmaydi)He talks as if he knew the city well.Xayoliy, haqiqatga to‘g‘ri kelmaydigan holat uchun o‘tgan zamon ishlatiladi.
Bekzod acted as if nothing happened. (aslida nimadir bo‘lgan)Bekzod acted as if nothing had happened.Xayoliy o‘tgan holat uchun past perfect (had + V3).
Don’t talk to me as if I am a child.Don’t talk to me as if I were (was) a child.Men bola emasman, shuning uchun xayoliy holat: were (was).
It looks as if to rain.It looks as if it is going to rain. / It looks like rain.As if dan keyin to‘liq gap (ega + fe’l) kerak, to + fe’l emas.

❓ Savol-javob Questions students often ask

Look like va look as if ning farqi nima?

Farq faqat ulardan keyin keladigan so‘zda. Look like dan keyin ot yoki olmosh keladi: She looks like her mother. Look as if dan keyin to‘liq gap: She looks as if she is tired. Sifat bo‘lsa, ikkalasi ham kerak emas: She looks tired.

“It looks like it’s going to rain” — bu to‘g‘rimi?

Ha, bu juda keng tarqalgan norasmiy shakl. Standart yozma ingliz tilida It looks as if it’s going to rain yoki It looks like rain (ot bilan) deyish ma’qul. Og‘zaki nutqda hamma like ni gap oldidan ishlatadi.

As if dan keyin nega ba’zan o‘tgan zamon qo‘yiladi?

Chunki o‘tgan zamon “bu haqiqat emas, bu faqat xayoliy tasavvur” degan ma’noni beradi. He talks as if he knew the city well — u aslida shaharni yaxshi bilmaydi. Gap hozirgi payt haqida bo‘lsa ham fe’l o‘tgan zamonda turadi. Haqiqat bo‘lishi mumkin bo‘lsa, odatdagi (vaziyatga mos) zamon ishlatiladi.

As if he were va as if he was — qaysi biri to‘g‘ri?

Ikkalasi ham. Were an’anaviy va rasmiy yozuvda afzal; was og‘zaki nutqda keng tarqalgan. “I” bilan ham shunday: as if I were / was a child.

As if va as though o‘rtasida farq bormi?

Ma’no jihatidan farq yo‘q. As though yozma nutqda, as if esa kundalik nutqda ko‘proq uchraydi. Ikkalasidan keyin ham bir xil qoidalar ishlaydi.

“What does he look like?” bilan “What is he like?” bir xil emasmi?

Yo‘q. What does he look like? — tashqi ko‘rinishi haqida (bo‘yi, sochi...). What is he like? — umuman qanday inson ekani haqida (xarakteri, odatlari), ba’zan ko‘rinishi ham (Unit 117). Javoblari ham boshqacha: He’s tall with dark hair. va He’s friendly and funny.

“I feel like going out” da like qanday ma’noda?

Bu yerda feel like + -ing “…qilgim kelyapti” degani, o‘xshashlik emas. Ot yoki gap bilan esa feel like “…ga o‘xshab tuyuladi” (★ bo‘lim).

2-mashq. Qavs ichidagi fe’lni to‘g‘ri zamonda yozing. Gap haqiqatmi yoki xayoliymi — qavsdagi izohga qarang.

🧠 Esda tuting

  • look / sound / feel / smell / taste + like + ot: looks like a film star, tastes like lemon.
  • look / sound / feel / seem + as if / as though + gap: It looks as if it’s going to rain. Sifat bilan like kerak emas: looks tired.
  • Og‘zaki nutqda like + gap ham aytiladi (It looks like it’s going to rain), rasmiy yozuvda as if / as though.
  • Haqiqat bo‘lishi mumkin → odatdagi (vaziyatga mos) zamon: She looks as if she is ill.
  • Xayoliy (rost emas) hozirgi holat → past simple: talks as if he knew the city well; were / was ikkalasi mumkin.
  • Xayoliy o‘tgan holat → past perfect: acted as if nothing had happened.
  • Ko‘rinishni so‘rash: What does he look like? (❌ How does he look like?).
