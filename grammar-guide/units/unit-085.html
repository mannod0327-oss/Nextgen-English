Some and any

Some va any
Pronouns and determiners · Olmoshlar va aniqlovchilar

🎯 Bu darsda nimani o‘rganasiz?

  • some darak gaplarda, any inkor va so‘roq gaplarda: I have some money. I don’t have any money. Do you have any money?
  • Taklif va iltimosda so‘roq gapda ham some: Would you like some tea? Can I have some water?
  • any darak gapda ham kelishi mumkin — “istalgan” ma’nosida: Take any book.
  • somebody, something, somewhere va anybody, anything, anywhere — ular ham xuddi shu qoidaga bo‘ysunadi.
  • Nomsiz ishlatilishi: Would you like some? I don’t want any.

some va any — noaniq miqdor so‘zlari: “ozgina, bir necha, qancha bo‘lsa ham”. Ular ko‘plik sanaladigan otlar (some flowers) va sanalmaydigan otlar (some water) bilan ishlatiladi. Aniq son yoki miqdor aytilmaydi.

O‘zbek tilida some va any uchun bitta so‘z yo‘q, ma’noga qarab so‘z tanlanadi. Some ≈ biroz, ozgina, bir nechta, ba’zi. Inkorda any ≈ hech qanday: Menda hech qanday pul yo‘q = I haven’t got any money. Savolda any ≈ biror, birorta: Sizda birorta savol bormi? = Have you got any questions? Gapdagi “istalgan” ham any: Istalgan kitobni oling = Take any book.

Eng oddiy qoida shunday: some — darak gaplarda; any — inkor va so‘roq gaplarda.

Qoida: some / any faqat ko‘plikdagi sanaladigan otlar (some eggs) va sanalmaydigan otlar (some rice) bilan ishlatiladi. Birlikdagi sanaladigan ot bilan a / an kerak: an egg (Unit 71).

Some va any ot bo‘lmasa ham ishlatiladi

Ma’no tushunarli bo‘lsa, ot tushiriladi:

  • “Would you like some more rice?” “No, thanks. I’ve had enough.”— Yana guruch olasizmi? — Yo‘q, rahmat. Yetarli.
  • I’d like to buy some oranges, but there aren’t any in the shop.Apelsin olmoqchi edim, lekin do‘konda umuman yo‘q.
  • I’ve got some photos of Bukhara. Do you want to see some?Menda Buxoroning suratlari bor. Ba’zilarini ko‘rmoqchimisiz?

Inkor ma’noli so‘zlardan keyin ham any

Gapda without, hardly, never, rarely, seldom, refuse kabi so‘zlar bo‘lsa, ular inkor ma’no beradi, shuning uchun any ishlatiladi:

  • He came to the exam without any pens.U imtihonga birorta ham ruchkasiz keldi.
  • Jasur was ill and refused to eat anything.Jasur kasal edi va hech narsa yeyishni istamadi.
  • We have hardly any time left.Bizda vaqt deyarli qolmadi.
  • Our teacher never gives us any homework on Fridays.Ustozimiz juma kunlari bizga hech qachon uy vazifasi bermaydi.

If bilan: if … any

If dan keyingi gapda ham, xuddi so‘roq gapdagidek, narsaning bor-yo‘qligi noma’lum. Shuning uchun odatda any ishlatiladi:

  • If you have any problems, please tell me.Biror muammongiz bo‘lsa, menga ayting.
  • Let me know if you need any help.Yordam kerak bo‘lsa, menga xabar bering.

Ba’zi gaplarda if so‘zi yo‘q, lekin ma’no if ga o‘xshaydi, shuning uchun ham any keladi:

  • I’m sorry for any mistakes in my letter.Xatimdagi xatolar uchun (agar bo‘lsa) uzr so‘rayman.
  • Anyone who arrives late will have to wait outside.Kim kechiksa, tashqarida kutishiga to‘g‘ri keladi.

Some inkor gapda ham keladi, ko‘pincha ega vazifasida bo‘lsa: Some people don’t like coffee. (Ba’zi odamlar qahvani yoqtirmaydi.) Bu yerda some people — ega, “ba’zi odamlar”, ya’ni boshqalari yoqtiradi. Any people don’t like coffee ❌ — bunday demaymiz.

Taklif va iltimos: so‘roq gapda ham some Offers and requests: some in questions

O‘zbek tilida bunday farq yo‘q: Choy ichasizmi? deymiz xolos. Inglizchada esa Would you like some tea? va Do you have any tea? bir-biridan farq qiladi: birinchisi taklif, ikkinchisi bor-yo‘qligini so‘rash.

Taklifda Would you like some …? eng muloyim shakl. Do you want some …? ham to‘g‘ri, lekin kamroq rasmiy. Would you like any …? ham ba’zan eshitiladi, lekin taklifda odatda some ishlatiladi — shunday eslab qoling.

Any = “istalgan” Any = it doesn’t matter which

Any darak gapda ham kelishi mumkin. Shunda u “qaysi bo‘lsa ham farqi yo‘q”, “istalgan” degan ma’noni beradi. Bunday ishlatilganda any bilan birlikdagi sanaladigan ot ham keladi:

  • You can sit at any table. They’re all free.Istalgan stolga o‘tirishingiz mumkin. Hammasi bo‘sh.
  • Call me any time — I’m at home all day.Istalgan vaqtda qo‘ng‘iroq qiling — men kun bo‘yi uydaman.
  • Any teacher in this school will help you.Bu maktabning istalgan o‘qituvchisi sizga yordam beradi.
  • Choose any colour. They are all the same price.Istalgan rangni tanlang. Hammasining narxi bir xil.
  • Anybody can learn to swim.Suzishni istalgan kishi o‘rganishi mumkin.
  • “What shall I cook tonight?” “I don’t mind. Anything.”— Bugun kechqurun nima pishiray? — Farqi yo‘q. Nima bo‘lsa ham.

Do you have any books?

Savol. Kitobingiz bor-yo‘qligini bilmayman.

Take any book.

Darak gap. Qaysi kitobligi muhim emas.

“Istalgan” ma’nosidagi any og‘zaki nutqda urg‘u bilan aytiladi. Yozuvda uni ma’nodan taniysiz: gapda “farq qilmaydi” degan fikr bo‘ladi.

Some of / any of

❓ Savol-javob Questions students often ask

So‘roq gapda har doim any ishlatamanmi?

Yo‘q. Oddiy savolda (javobini bilmasangiz) — any: Do you have any brothers? Lekin taklif va iltimosda yoki “ha” javobini kutayotgan savolda — some: Would you like some tea? Can I have some water? Farq — so‘zlovchining niyatida.

Inkor gapda some umuman ishlatilmaydimi?

Odatda ishlatilmaydi. Istisno: some gapning egasi bo‘lsa va ma’no “ba’zilari” bo‘lsa: Some students didn’t come. (ba’zi talabalar kelmadi — boshqalari keldi). Ba’zan some ta’kid bilan qarama-qarshilikni ko‘rsatadi: I didn’t eat some of the cakes (ba’zilarini yemadim, boshqalarini yedim). Boshlovchilar uchun asosiy qoida: inkorda any.

“Any” darak gapda xato emasmi? “Take any book” to‘g‘rimi?

To‘g‘ri, chunki bu yerda any “istalgan” degan boshqa ma’noda ishlatilgan. Bunday any bilan birlikdagi sanaladigan ot ham keladi: any bus, any day, any student.

Some + birlikdagi ot (some man, some book) degan shakl bormi?

Bor, lekin ma’nosi boshqa: some + birlikdagi ot “kimligi yoki nimaligi noma’lum” degan ma’noni beradi: Some man called while you were out (qandaydir bir kishi qo‘ng‘iroq qildi). Oddiy “bitta kitob” uchun a book deymiz.

Nega “If you have any problems” da any ishlatilgan?

Chunki if dan keyin muammo borligi yoki yo‘qligi noma’lum, ya’ni so‘roq gapga o‘xshash holat. Shuning uchun any. Lekin so‘zlovchi muammo bo‘lishini kutayotgan bo‘lsa, some ham aytiladi: If you want some more, just ask.

“Somebody” bilan “someone” o‘rtasida farq bormi?

Yo‘q, ma’nosi bir xil. Someone/anyone yozuvda biroz ko‘proq uchraydi, somebody/anybody so‘zlashuvda. Ularning ikkalasi ham birlik va fe’li birlikda.

“Some” va “a lot of” bir xilmi? “Some” ning aniq miqdori bormi?

Aniq miqdori yo‘q. Some — “noma’lum, ahamiyatsiz miqdor” (ozgina yoki bir necha). Ko‘p narsa uchun a lot of, plenty of (Unit 87).

Uncountable ot bilan some qanday ishlatiladi (some advice, some information)?

Xuddi shu qoida: some advice, some information, some news, some furniture. A / an ishlatilmaydi. Bitta bo‘lakni aytish kerak bo‘lsa, a piece of (a piece of advice) deymiz (Unit 69–70).

🧠 Esda tuting

  • some — darak gaplarda; any — inkor va so‘roq gaplarda (I have some. I don’t have any. Do you have any?).
  • Ikkalasi ham faqat ko‘plik sanaladigan va sanalmaydigan otlar bilan; birlikdagi sanaladigan ot bilan a / an.
  • Taklif va iltimosdagi so‘roq gapda some: Would you like some tea? Can I have some water?
  • if dan keyin va without, hardly, never bilan odatda any.
  • Darak gapdagi any = “istalgan”: Take any book. Anybody can do it.
  • somebody / something / somewhere va anybody / anything / anywhere ham xuddi shu qoida bilan. Fe’l birlikda; sifat keyin keladi: something hot.
